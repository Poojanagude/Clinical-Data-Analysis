# Clinical Data Analysis Dashboard 

##  Project Overview

The Clinical Data Analysis Dashboard is an interactive Business Intelligence solution developed using Power BI to analyze healthcare and hospital performance data. The dashboard transforms raw clinical datasets into meaningful insights for monitoring infections, readmissions, admissions, and mortality trends across hospitals and years.

This project focuses on healthcare analytics, KPI visualization, and trend analysis to support data-driven decision-making in the healthcare domain.


# Business Objective

The objective of this project is to provide a centralized and interactive analytical dashboard that helps analyze:

* Infection trends
* Readmission patterns
* Total admissions
* Mortality analysis
* Hospital-wise performance
* Year-wise healthcare trends
